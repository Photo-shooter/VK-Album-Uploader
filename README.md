# VK-Album-Uploader
Скрипт для Tampermonkey. Гарантированно загружает любое разумное количество фото в альбом группы в 1 или 3 потока, при загрузке в 1 поток гарантированно сохраняется алфавитная последовательность файлов.
Необходимость скрипта вызвана тем что ВК по каким то причинам при загрузке большого количества фото в альбом часть из них пропускает, выдавая сообщение о неудачной загрузке без указания имени файла.
Данный скрипт проверяет успешность каждой загрузки файла, при необходимости повторяет загрузку до 3 раз и ведет лог.
Для работы скрипта необходимо расширение браузера Tampermonkey https://github.com/Tampermonkey/tampermonkey?ysclid=mwabrgpq9u557578323 (также есть в addons браузера) или аналогичное.
